잠깐! 제출 전에 확인해볼까요?

결과물이 제대로 적용되지 않았다면 괜찮아요.
아래 방법으로 배경, 크기, 파일 용량을 직접 수정할 수 있어요.

1
배경 제거하기 이미지에 불필요한 배경이 있다면 투명하게 만들어주세요.

1. remove.bg에 접속
2. 이미지를 업로드
3. 자동으로 제거된 배경 확인
4. 배경이 제거된 PNG 파일로 저장

remove.bg에서 배경 제거하기 ↗
2
크기 줄이기 · 128 × 128px 이모지에 맞게 이미지 크기를 조절해보세요.

1. EZGIF Resize에 접속
2. 방금 만든 이미지 또는 GIF 업로드
3. Width 128 / Height 128 입력
4. Resize 실행 후 결과 파일 저장

GIF MEME

영상 속 장면을 GIF 밈으로 만들어볼까요?

재미있는 영상이나 화면에서 원하는 장면만 캡처하고,
짧은 문구를 더해 움직이는 GIF 이모지로 만들어보세요.

1
원하는 장면 선택하기 이모지로 만들고 싶은 영상이나 화면을 준비하고, Chrome Capture에서 원하는 영역을 선택합니다.
2
짧게 녹화하기 선택한 영역을 녹화하고 이모지로 사용할 장면만 짧게 담아줍니다.
3
GIF로 저장하기 원하는 장면까지 녹화했다면 GIF 파일로 저장합니다.
4
GIF에 글자 넣기 저장한 GIF를 EZGIF의 Add Text에 업로드하고 원하는 짧은 문구를 입력합니다.
5
글자 스타일과 위치 조절하기 글자의 크기, 폰트, 색상과 위치를 조절하고 미리보기로 결과를 확인합니다.
6
완성된 GIF 저장하기 결과를 확인하고 마음에 들면 완성된 GIF 파일을 저장합니다.
